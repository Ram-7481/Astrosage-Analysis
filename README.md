# Astrosage Customer Analysis

## Project Overview
This project focuses on analyzing customer behavior, engagement patterns, and business performance using Excel. The objective was to identify key customer trends, measure business KPIs, and generate actionable insights to support data-driven decision-making.

## Objectives
- Analyze customer demographics and behavior.
- Identify factors influencing customer engagement.
- Evaluate business performance metrics.
- Generate insights to improve customer retention and growth.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Power Query
- Lookup Functions
- Conditional Formatting
- Dashboarding & Data Visualization

## Key Analysis Performed
- Customer segmentation analysis.
- Revenue and performance trend analysis.
- Customer activity and engagement tracking.
- KPI monitoring and reporting.
- Data cleaning and transformation.

## Key Insights
- Identified high-value customer segments.
- Discovered customer behavior patterns affecting engagement.
- Highlighted performance trends and business opportunities.
- Generated actionable recommendations through data analysis.

## Conclusion
This project demonstrates data cleaning, analysis, reporting, and visualization skills using Excel to transform raw data into meaningful business insights and support strategic decision-making.
